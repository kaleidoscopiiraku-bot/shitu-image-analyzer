# MiMo V2 · v2.0.0

Shitu has been renamed **MiMo看图**.

- Searchable style-prompt library with categories, sorting, full before/after previews, details and copy.
- Local favorites from cards and details.
- QR/promotional-image preview selection fixed.
- Copyable prompts request an independent styled image rather than a photo comparison.
- Existing image analysis, Chrome right-click/side-panel, region capture, Finder services and ten recent analyses retained.
- Per-device random pairing with extension Options setup; no embedded account or pairing secret.

Includes 233 upstream-licensed style entries and examples under their individual noncommercial terms. Original source links and licenses are included. Personal Xiaohongshu material is not redistributed.

Download the DMG or App ZIP and copy MiMo看图.app to Applications. The Chrome extension is a separate asset and requires local pairing. Apple Silicon development build; ad-hoc signed and not notarized. The desktop bridge requires Python 3.9+. Model weights, private LoRA adapters, training data and Codex CLI are not bundled. Image generation uses a manual copy-and-paste workflow.

Original application identity and local data directory are retained. No personal settings, API keys, favorites, histories or model data are uploaded.
