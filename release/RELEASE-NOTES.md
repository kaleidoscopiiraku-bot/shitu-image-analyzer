# MiMo看图 V2 · v2.0.0

「拾图」正式更名为 **MiMo看图**。

- 新增风格提示词库：搜索、分类、排序、完整原图/成片对比、详情与复制。
- 新增本机收藏夹，常用画风可从卡片或详情收藏。
- 修复误用二维码作为效果预览的问题。
- 复制提示词移除照片分屏要求，生成完整风格化成片。
- 保留已有图片分析、Chrome 右键/侧栏、框选、Finder 服务和最近十条分析。
- 改为每台 Mac 随机生成配对码；扩展从选项页面手动连接，安装包不内置账号或配对码。
